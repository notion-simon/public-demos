# Public Demos

Static demo pages served with GitHub Pages.

## GitHub Pages setup

This repository is designed to publish from the `main` branch at the repository root.

After pushing changes, GitHub Pages can serve the site from:

`https://notion-simon.github.io/public-demos/`

## Local preview

Use any static file server from the repository root:

```bash
python3 -m http.server 3000
```

Then open:

`http://localhost:3000/`
